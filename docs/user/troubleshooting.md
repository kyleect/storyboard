# When something goes wrong

## A tool failed

If a tool fails, the helper usually tells you and tries something else. Sometimes it can't. For example, it may look for a file that isn't there.

## Errors page

Click **Errors** in the rail to see every problem that happened.

Each one shows what failed and where. A red number appears on the rail when there are new ones.

## Debug view

Open a chat and choose **Debug**. It lists everything that happened, step by step, in order.

Use it to see what the helper was asked, what it did and what came back.

## Common questions

**The helper doesn't answer.**
Check that the model server is running. Check **Settings, Models**.

**The helper says it can't use a tool.**
The tool may be off, or not given to that agent. See [Approvals and tools](approvals-and-tools.md) and [Agents](agents.md).

**The helper can't see my folder.**
Attach the workspace to the chat or project. Tick the parts to search. See [Workspaces](workspaces.md).

**I can't switch profile.**
Wait until the helper stops. Then try again.

**A form didn't update.**
Reload the page.

## Trash and restore

Chats, projects and more go to the trash first. Nothing is lost right away.

1. Open **Settings**, **Trash**.
2. Press **Restore** next to the item.

Items are removed for good after a number of days you can change.
