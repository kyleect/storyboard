# Files

Helpers can keep documents for you. A file might be a plan, a list or a draft.

## Where files live

Every file has a place:

| Place            | Who can see it             |
| ---------------- | -------------------------- |
| **This chat**    | Only this chat.            |
| **This project** | Every chat in the project. |
| **Everywhere**   | Every chat.                |

Use **Everywhere** for things like your preferences.

## Work with files

1. Click **Files** in the rail.
2. Open a folder to see what is inside.
3. Double-click a file to open it.
4. Change the text and save.

You can also create, rename and delete files here.

## Let a helper write a file

Ask for it. For example, "Save the plan as a file."

The helper will show **Save a new file**. Check the name and place, then save.

## Pictures and sound

Files can hold pictures and sound too, not just text.

## Older versions

Files keep their history. You can look at an earlier version and bring it back.

## Files and your computer

These files live inside the app. They are not on your computer's disk. To use files from your computer, see [Workspaces](workspaces.md).
