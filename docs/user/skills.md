# Skills

A skill is a set of written tips. It tells helpers how to do one kind of job well.

For example, a skill called "friendly-tone" might say: "Write like you are talking to a friend. Keep sentences short."

## How skills work

- Helpers see a short list of skills.
- When one fits the job, the helper reads it and follows it.
- You don't have to ask.

## Built-in skills

The app comes with a few skills about decisions, goals, tasks and structured data.

## Make a skill

1. Click **Skills** in the rail.
2. Make a new skill.
3. Choose a short name. Use lowercase words with dashes, like `friendly-tone`.
4. Write a **description**. Say when the skill should be used.
5. Write the tips in the **SKILL.md** file.

## Tips for good skills

- One skill, one job.
- Short steps.
- Say _when_ to use it in the description.
