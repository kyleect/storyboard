# Settings

Click the gear in the rail. Settings has these areas on the left: General, Chat, Agents, Tools and Trash.

## General

### Models

- **Default model.** The model new chats use.
- **Default reasoning effort.** How hard the model thinks. Leave it empty to let the server choose.
- **Embedding model.** Helps searching by meaning. Leave it empty to search by keywords only.

Press **Save** after you change something.

### Server

Where the model server lives. You usually won't need to change this.

### Profiles

A profile is a separate copy of everything: agents, files, chats and settings. Use one for work and one for home, for example.

- Type a name and press **Create**.
- **Switch to** changes profile. You can't switch while a helper is working.
- **Rename** and **Trash** do what they say.

You can also switch from the Profile button in the rail.

### Look & Feel

Pick your theme color. It is saved in this browser.

## Chat

### System prompt

These are instructions every chat starts with. You can change them. Special words in double curly brackets, like the date, are filled in for you.

### Instructions

The wording used when the app lists your skills, tools, files and so on to the helper.

### Session titles

- Turn automatic naming on or off.
- Pick the model that writes titles.
- Change the title prompt.

### Editing

- **When you save an edit.** Keep the old message on a branch, or overwrite it. Overwriting loses the old text.
- **Answer after a branched edit.** When on, the helper replies right away to the edited message.

### Media

- How many earlier pictures and sounds stay in view.
- Which model describes pictures and sound for models that can't see them.

## Agents

### Subagents

- **Subagent depth.** How many levels of helpers can start helpers. 0 turns it off.
- **Reminders.** How many times a stuck helper is nudged to finish.

### Limits

Caps that keep things from running away.

- **Loop limit.** The most steps one run takes before it stops.
- **Copy limit.** The most files one copy or move can name.
- **Workspace read size.** The most text of one folder file a helper reads at once.
- **Skill limits.** How big a skill, and how many files in it, can be.

## Tools

See [Approvals and tools](approvals-and-tools.md).

## Trash

- Choose how many days things stay in the trash.
- **Restore** brings something back.
- **Delete forever** removes it for good.
- **Empty trash** removes everything.
