# Storyboard user guide

Storyboard is an app where you chat with AI helpers. They can write, plan and organize things for you. They can keep files, track lists, and read notes from a folder on your computer. You stay in charge: they ask before they change anything important.

This guide shows you how to use it, one step at a time.

## The window

- **Left rail.** Icons for Chats, Agents, Skills, Files, Structured data, Workspaces, Errors, Profile and Settings.
- **Chat list.** Your chats and projects, shown as a tree.
- **Tabs.** Each thing you open gets a tab.
- **Status bar.** Small facts about what you have open.
