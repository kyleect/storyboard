# Structured data

Structured data is a way to keep lists and records that always look the same. Think of a task list or a guest list.

## Two parts

- A **schema** is the shape. It says what boxes each record has. For example, a Guest has a name and an RSVP.
- A **record** is one item that follows the shape. For example, the guest "Maya".

## Built-in shapes

- **Task.** Something to do.
- **Goal.** Something you want to reach.
- **Decision.** A choice you made and why.

## Make a schema

1. Click **Structured data** in the rail.
2. Make a new schema.
3. Name it and describe it.
4. Add fields. Each field has a name and a type, such as text, choice or yes/no.
5. Mark the fields that must be filled in.
6. Save.

## Make and edit records

1. Open a schema.
2. Make a new record.
3. Fill in the form.
4. Save.

You can switch between **Form** and **JSON**. Form is easier.

## Let a helper do it

Ask, "Add these steps to my task list." The helper creates a record for each step. It asks you first. See [Approvals and tools](approvals-and-tools.md).

## Places

Like files, schemas and records can belong to a chat, a project, or everywhere.
