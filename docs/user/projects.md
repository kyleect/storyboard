# Projects

A project keeps related things together: chats, files, lists and notes about the job.

## Make a project

1. Press the new project button.
2. Type a **Name**.
3. Add a **Description** if you like.
4. Pick a **Color**. It shows on the project's folder.
5. Press **Create**.

## The project page

Open a project to see its page.

You can:

- Change the **Color**.
- Choose a **Default agent**. New chats in this project start with that helper.
- Write a **Description**.
- Write a **System prompt**. These are standing instructions. Every chat in the project follows them.
- Attach a [workspace](workspaces.md).
- See all the project's chats in a table.

Remember to press the save button under a box after you change it.

## Start a chat in a project

Press **New chat** on the project page. The chat follows the project's instructions and can use the project's files and data.

## Remove a project

Press **Move project to trash**. You can bring it back from the trash. See [troubleshooting](troubleshooting.md).
