# Approvals and tools

A tool is something a helper can do, like save a file or read a note. You decide which tools can run on their own and which must ask first.

## Approval box

When a helper wants to use a tool that asks, you see a box.

| Button                     | What it means                   |
| -------------------------- | ------------------------------- |
| **Allow once**             | Yes, just this time.            |
| **Allow for this session** | Yes, for the rest of this chat. |
| **Always allow this tool** | Yes, every time from now on.    |
| **Deny**                   | No.                             |

For folders on your computer the buttons end with the workspace name.

## Many at once

When a helper wants to do several things, you get a review box.

- Tick the ones you want.
- **Approve selected** allows the ticked ones.
- **Approve all** allows everything.
- **Deny all** says no to all.

## Permissions page

1. Open **Settings**.
2. Choose **Tools**, then **Permissions**.

For each tool you can pick:

- **Always on**. It runs without asking.
- **Ask**. It asks you first.
- **Off**. It can't be used.

A group heading sets all its tools at once.

## Extra tools (MCP servers)

You can add extra tools from other programs.

1. Open **Settings**, **Tools**, **MCP servers**.
2. Add the server.
3. Wait for it to say **Connected**.

New tools start on **Ask**. Only add servers you trust.
