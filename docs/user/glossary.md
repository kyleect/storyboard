# Words used in the app

| Word              | Meaning                                               |
| ----------------- | ----------------------------------------------------- |
| **Agent**         | A helper with its own job, instructions and tools.    |
| **Approval**      | Your yes or no before a tool runs.                    |
| **Branch**        | Another version of a chat from one message on.        |
| **Chat**          | A conversation with a helper.                         |
| **Default agent** | The helper new chats start with.                      |
| **Fork**          | A copy of a chat, up to one message, as a new chat.   |
| **Model**         | The AI that writes the replies.                       |
| **Profile**       | A separate copy of everything, like a second account. |
| **Project**       | A place to keep related chats, files and data.        |
| **Record**        | One item in structured data.                          |
| **Schema**        | The shape of a kind of record.                        |
| **Skill**         | Written tips that teach helpers a job.                |
| **Subagent**      | A helper started by another helper.                   |
| **System prompt** | Standing instructions a helper always follows.        |
| **Tool**          | Something a helper can do, like save a file.          |
| **Workspace**     | A folder on your computer that helpers can use.       |
