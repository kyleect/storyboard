# Examples

Three short walk-throughs.

## 1. Plan a birthday party

You will make a project, answer some questions, and keep a plan.

1. Make a project called "Birthday Party". See [Projects](projects.md).
2. Start a chat in it.
3. Type: "Help me plan a dinosaur party for an 8-year-old."
4. The helper shows a form. Fill it in and press **Submit**.

5. The helper offers to save a plan. Check the name and press **Save**.

6. Type: "Add the next steps to my task list."
7. Approve the new tasks.

You now have a plan file and a task list in the project.

## 2. Summarize a notes folder

You will let a helper read a folder on your computer.

1. Add a workspace for your notes. See [Workspaces](workspaces.md).
2. Tick the parts to search.
3. Attach it to a chat.
4. Ask: "What do my garden club notes say about seeds?"
5. Read the answer.
6. Ask: "Save these as a to-do note in my folder."
7. The helper asks first. Press **Allow once**.

## 3. A helper that asks about allergies

You will make a helper with one simple rule.

1. Go to **Agents** and make a new agent called "Recipe Helper".
2. Write the system prompt: "You suggest easy dinners. Ask about food allergies first."
3. Turn on **Can be started by other agents**.
4. Open a new chat and type: "I need dinner ideas for the week."
5. The default helper passes the job to Recipe Helper.
6. Answer the allergy question.

You get five dinner ideas back in your chat.
