# Workspaces

A workspace is a folder on your computer that you let helpers use. For example, your notes folder.

Helpers can only see the folders you connect. They can read them. They can only change things if you allow it.

## Add a workspace

1. Click **Workspaces** in the rail.
2. Press **New workspace**.
3. Choose the folder.
4. Give it a name.

A workspace can be **Writable** or read-only. Read-only means helpers can look but not change.

## Choose what helpers can search

Open **Searched parts**. You can tick the whole folder or only some folders and files. Helpers search only what you tick.

Press **Rescan** if you added new files.

## Use a workspace in a chat

1. Open the project page, or the chat's **Workspaces** view.
2. Choose the workspace and attach it.
3. Ask your question. For example, "What do my garden club notes say about seeds?"

The helper looks through the folder and answers.

## Changes need your OK

If a helper wants to write a file in your folder, it asks first.

You can choose:

- **Allow once**
- **Allow for this session**
- **Always allow this tool**
- **Deny**

## Remove a workspace

Press **Move to trash**. Your folder on the computer is not touched.
